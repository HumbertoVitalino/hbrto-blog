## 💡 Dicas Rápidas

**Para desenvolvimento:**
```bash
npm run dev      # Rodar localmente
npm run build    # Compilar para produção
npm run lint     # Verificar código
```

**Para estudar o código:**
- Procure por comentários `TODO:` no código
- Explore em `DEVELOPMENT.md` como estender
- Veja exemplos em `components/ui/` de como criar componentes

**Para debugar:**
- Abra DevTools (F12) no navegador
- Verifique console para erros
- Use Network tab para ver API calls
- Verifique Supabase Dashboard → Logs
